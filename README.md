# catch note if u can

เกมฝึกอ่านโน้ตบนบรรทัดห้าเส้น กดชื่อโน้ตให้ทันก่อนการ์ดจะตกถึงเส้น

- ไฟล์เดียว `index.html` ไม่ต้องติดตั้งหรือ build
- รองรับกุญแจเทรเบิล เบส อัลโต และเทเนอร์ พร้อมเครื่องหมายแปลงเสียง
- ตอบได้ 2 แบบ คือพิมพ์ชื่อโน้ต หรือกดบนแป้นเปียโน
- บันทึกคะแนนสูงสุดรายระดับ และประวัติการเล่นล่าสุด (เก็บในเบราว์เซอร์)
- เปลี่ยนพื้นหลังหน้าปกได้ รวมถึงอัปโหลดรูปของตัวเอง

## เล่นออนไลน์

เปิดลิงก์ GitHub Pages ของรีโปนี้ หรือเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์โดยตรง
